# Pokémon pomodoro website

A fun Pokémon pomodoro website and quite rudimentary at best.

### Features

- A to-do list, remove and add and check off items as you please

- A fun Sylveon GIF to accompany you as you work!

- A working focus and break timer (25/5), with abilities to start, stop and reset them


### Features to be added
- Switch Pokémon
- Skip between breaks and focus
- Long break
- Ambience
- Set manual and focus times
- Beautification
